# AI-Based-MCQ-Test-Generator-from-PDFs-using-Streamlit-and-GeminiPro
AI-powered web app that converts PDFs into MCQ quizzes using Streamlit, Gemini Pro, LangChain, and FAISS. Extracts text, splits it into chunks, and generates 5 questions per batch with semantic embeddings. Enables fast, scalable, and automated assessment creation.
